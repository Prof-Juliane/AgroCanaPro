# AgroCana Pro 🌾🚜

Sistema integrado de inteligência agrícola e planejamento sucroenergético voltado para o monitoramento de safras, cotações de mercado e gestão de talhões no setor canavieiro.

---

## 🚀 Sobre o Projeto
O **AgroCana Pro** foi desenvolvido para centralizar indicadores do setor sucroenergético (Centro-Sul), oferecendo suporte à tomada de decisão agronômica e financeira. A plataforma integra dados de mercado em tempo real, estimativas de produtividade e dimensionamento de insumos com base em parâmetros técnicos oficiais.

## 📊 Principais Funcionalidades
- **Painel de Indicadores de Mercado:** Acompanhamento de cotações de referência (**CEPEA/ESALQ** e **CONSECANA-SP**), incluindo ATR acumulado, açúcar cristal e etanol (hidratado e anidro).
- **Simulador de Faturamento (ATR):** Ferramenta interativa para estimativa rápida de receita bruta com base em área (ha), TCH esperado (Toneladas de Cana por Hectare) e ATR médio.
- **Atalhos Rápidos de Manejo:** Diretrizes e recomendações para reforma/cana-planta e manutenção de cana-soca.

## 🛠️ Tecnologias Utilizadas
- **Front-end:** HTML5, CSS3 / TailwindCSS, JavaScript
- **Parâmetros Agronômicos:** Baseados nas recomendações técnicas oficiais para a região Centro-Sul (Boletim 100 IAC).
